**口径**：只比较最终数学、物理与数值结果；不计界面、工程组织、报告篇幅、自检数量或中间工程文件是否上传（多家未上传中间文件，不因此扣科学分）。

**指标与权重声明**：采用原标准第 1–8 项（物理模型/数学方程/单位与坐标/拉格朗日点/数值积分器/收敛与精度/守恒量表现/稳定性与边界）**等权各 10 分，合计 /80**。与样例权重（20/15/25/25/15 五维）不同，分数不可直接平均比较。

**统一实验电池（五家同初值、同步长梯、同时长）**：B1 拉格朗日点坐标与残差；B2 规定轨道 B（近地高频，周期 0.033 TU）步长梯 h=0.01/0.005/0.0025 收敛阶；B3 轨道 A（L4 蝌蚪 T=100）与轨道 B（T=30）Jacobi 漂移；B4 辛有界性（T=100 vs T=1000）；B5 边界五子项（地心/月心/逃逸/近月擦碰/非法输入）；B6 惯性系转换核验；B7 外部锚点对照。全部经页面引擎实测 + Python 逐行重写公式独立复算交叉验证。

> 关键工况事实：规定步长梯对轨道 B 处于欠分辨区，五家 RK4 全部远离 4 阶（p≈−3.3，渐近区补测与逐位复刻证明实现正确），故实现正确性（s5）五家均满分，收敛（s6）区分度全在第二积分器实测。

### 推荐

**本评审推荐 zcode--glm-5.3maxlinux（75.5）。** 理由（全部绑定实测）：GL4 辛积分在 L4 蝌蚪轨道 T=100 与 T=1000 的 Jacobi 漂移同为 2.2e-15（浮点舍入底上精确有界，教科书级长期模拟演示）；唯一在电池规定网格上干净通过收敛阶的辛积分器（p=3.90，R=14.92≈16）；边界五子项唯一全科干净（撞地/撞月立即停机、逃逸自动停机并标记、非法输入拒绝告警、近月擦碰万步无 NaN）——老派数值天体力学专家亲手施压时最少露怯。

**翻盘条件（如实给出）**：若专家组以「与 JPL 星历内嵌对照」为硬门槛 → 改选 codex-6astra-xhigh（锚点实测 8.95e-16，正则形式 C=−2H 体系最贴近教科书）；若最看重极端工况自适应精度与文献锚定广度 → 选 harnessL-ds-4.1flashmax（GBS 1.64e-10 领先 4 个数量级、九种积分器全验证、锚点 1.39e-16；但其完全无惯性系转换，s3 封顶 7）。榜首与第二名仅差 0.5 分，权重敏感性已说明。

**校准说明**：终评 5 份初评后经一轮横向校准（同工况同表现同分；欠分辨工况罚只计入 s6；单项调整 ≤±1.5），调整 9 处，原始分与校准理由见 scores.json 及各 .sci 记录。glmlinux 的 s6 受幅度上限约束（6→7.5，实测价值≈8.5），榜首差距实为保守估计。
