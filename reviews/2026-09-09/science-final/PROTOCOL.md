# 前四名科学终评：测试口径

评审者：**`codex-gpt-6-astra-xhigh`**。本文件对应该专家“10+4”评审中的“4”，与[十项评阅](../README.md)成套保存。

对象固定为原总榜前四：gptweb、codex、zwin、ds，仍使用 ac5a306 中的最终 HTML。新增评阅只讨论数学、物理和数值结果，不改变原 README 的综合评分。

在扩展数值运行前确定以下口径：

- 不计界面、代码组织、工具、文件数量、报告篇幅、迭代过程或自检条数；缺少中间文件不扣分。
- 对四份最终 HTML 中实际交付的函数运行同一套外部测试。正确的结果可以由评阅方证实，不要求参赛者事先保存相同测试。
- 每份都测试 RK4，另测试其已交付的最高阶固定步长辛方法：Codex Yoshida-4、GPT Web SY4、DS Yoshida-6、zcode Windows 中点法 Yoshida-4 复合。DS 的自适应 GBS 另行测量，不能因非辛就否定有限时间精度。
- 比较相同无量纲状态、时间和步长，按各自质量参数分别求参考解。这个比较不控制力评估数，不解释为计算效率排名。
- 同一套八种轨道：一般光滑状态、宽绕地轨道、近地轨道、近月轨道、L1 扰动、L4 扰动、偏心绕地轨道、共同月球飞越。每种固定步长跑 h、h/2、h/4，并报告全状态误差及收敛，不能只看 Jacobi 漂移。
- 长期另测 L4 的 T=1000、h=0.01 与绕地 T=100、h=0.001；记录最大 Jacobi 漂移和各时间段漂移，并做多状态正则辛性、时间反向检验。
- 参考解为不调用参赛代码的 DOP853，使用更严格容差/步长复算，并以惯性系移动双主星方程交叉检查。长时敏感轨道不把微小相位差机械解释为科学失败。
- 科学描述也是产物：飞越是否发生、同一月距出入的惯性速率变化、L4 特征周期等数值主张必须成立。报告排版不计分，错误物理结论计分。
- 已实测的跨表面步只评价模型有效域，不将极端输入表现等同于常规轨道精度。

终评分五项，总计 100 分：物理方程与量纲/坐标自洽 20；平衡点与动力学性质 15；轨迹精度与收敛 25；长期守恒与几何结构 25；物理结论及有效域 15。分数是公开量表下的专家式判断，不是概率或统计显著性；四份的严格名次是否稳健需随实测和权重敏感性一并说明。
