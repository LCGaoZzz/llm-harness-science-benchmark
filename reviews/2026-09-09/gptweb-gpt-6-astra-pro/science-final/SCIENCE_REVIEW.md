## 本轮新增的实际计算

使用原最终HTML的原数值函数，独立求解L4长跑 T=500、绕地长跑 T=50、共同近月飞越 T=0.8。每一固定方法运行标称步长及半步长；DS GBS运行原始默认容差及加严容差。所有完整四维状态与独立DOP853旋转系参考比对，同时使用纯牛顿引力、移动双主星的惯性系实现做交叉验证。参考自身加密差和跨参考系差均逐条保留。

终态误差范数采用无量纲状态[x,y,vx,vy]的欧氏范数。它不是严格误差上界。以下是共同绕地例子的代表结果，初值[0.18-mu,0,0,sqrt((1-mu)/0.18)-0.18]，T=50；固定步长h=0.001；DS GBS取rtol=1e-13、atol=1e-16、k=5、Bulirsch序列、初始h=0.001：

| 提交 / 方法 | 四维终态差 | 最大绝对Jacobi漂移 |
|---|---:|---:|
| DS / GBS | 4.70e-10 | 1.98e-12 |
| DS / Yoshida-6 | 7.55e-10 | 1.22e-12 |
| GLM-Windows / sym4 | 2.74e-5 | 4.64e-11 |
| GPTweb / SY4 | 3.76e-5 | 1.03e-10 |
| Codex / Yoshida-4 | 3.76e-5 | 1.03e-10 |
| 四份共同RK4基线（范围约值） | 4.67e-6 | 2.12e-8 |

这里比较交付作品所具有的方法结果，不是等力评估次数、等CPU成本的算法竞速。末行也揭示，有限时段内RK4可以比四阶辛法有更小的状态误差，同时其Jacobi漂移较大；因此不能只看“辛”标签或单一守恒量。

**补充步长敏感性复查同样重要：**将共同绕地RK4步长进一步减到1e-4和5e-5后，四份都可达到很高精度。每份两档中较小的终态参考差分别为GPTweb 3.65e-11、Codex 1.10e-10、GLM-Windows 3.91e-12、DS 2.42e-10；参考本身交叉差约1e-11到7e-11。地板附近不得据此排名，也不能把GLM-Windows的3.91e-12当作经过证明的绝对精度。DS用GBS加严容差的状态差也进入该参考地板附近。

因此，DS的优先推荐不是“其他三份算不准”。它的优势是最终产物同时交付经实算支持的高阶固定步方法和实际误差自适应方法，在多个动态尺度的测试中给出高质量结果。允许充分缩小步长后，其精度不是排他的；其分数只小幅领先。

## 物理结果与科学解释

### GPTweb 与 Codex不应因工程材料差异拉开分数

共同输入下两份的RK4和四阶正则分裂结果近乎一致。它们的月球飞越在月距0.1 DU的入/出射截面均有正的质心惯性速率增益：GPTweb约0.47026 VU，Codex约1.40516 VU。初值不同，这两个增益不可用来给两者排序；只用于核验各自“引力辅助”现象成立。不能以惯性坐标画面、箭头、是否额外上传验证脚本等因素拉开纯科学分数。

### DS的真实局限

允许域自检使用当前C构造2Ω-C，代数上恒等于v²，不能独立证明初始C0禁区未被越过。最终GBS元数据固定标8阶，而外推层数k可改变；这影响科学结果解释的一致性，不使已实测正确的GBS内核变错。近月预设从非常靠近月球处开始，T>=0内只有0.1DU出射截面；不凭不等距离处初末速度就声称完整入/出射增益。其实际轨迹完成且无撞击，月心最近距离约0.005604 DU。

### GLM-Windows的主要扣分不是算法

固定隐式中点及四阶复合均正确，数值项表现良好。扣分来自最终说明的可复现科学出入：

1. 写L4长周期约29.9 TU。对其mu，线性频率满足 w²=(1±sqrt(1-27mu(1-mu)))/2，长周期实际约21.06980 TU，短周期6.58269 TU。对实际有限扰动做300TU独立传播，慢模相位估计亦约21.0TU，而非29.9。有限振幅运动并非严格单一周期，此诊断不被冒称为严格周期解。
2. 写月球飞越约t=1.3TU、r=0.028DU。使用最终交付的原初值独立求解，T<=10内最近月距约0.05459365DU、时刻6.29597639TU。距月0.1DU的前后速度略增，说明飞越现象不全是假的；错误的是标注的定量结果。

这些是最终产物里的科学声明，不是中间工程材料缺失；结果导向并不意味着免除主动给出的错误科学结论。

## 推荐的含义与限制

按本轮纯科学结果权重，我会先向传统天体力学/数值数学专家展示DS，再将GPTweb与Codex并列作为同等级候选。理由是数学成立、数值结果强、精度控制实际可用，而不是功能数量或开发过程。

不能推断真实专家团队必然这样投票。本轮只覆盖有限的典型样例；不证明任意混沌轨道长期相位都准确，不代表生产航天任务级认证。改变“精度范围”与“失败输出控制”的权重，前三名可能互换；分数不是统计置信度。没有因中间文件未上传扣分，也没有人工修复参赛代码。

## 文件与复现

- new_measurements.json：全部标称/半步长、GBS容差比较、参考加密和惯性系核对。
- physical_claims.json：真实原始预设、线性L4频率、实际L4扰动和事件定位后的月球飞越。
- refinement_check.json：后续所有四份RK4更小步长敏感性检查，不隐去不利于首选的结果。
- audit/inputs/：四份未经修改的最终原HTML；audit/entries.json记录SHA-256。
- scores.json：评分、权重、排除项和逐项理由。

依赖：Python、numpy、scipy、playwright、Chromium。环境版本见environment.json。本环境以set_content加载全部HTML并阻断外部请求，未声称本轮做了file://双击复核。

在解包目录执行：

```bash
python scripts/extra_results.py
python scripts/physical_claims.py
python scripts/refinement_check.py
```

脚本默认Chromium路径/usr/bin/chromium；其他系统须将launch中的executable_path改成自己的Chromium路径，或安装Playwright Chromium并使用其默认launch。重新执行覆盖对应JSON，请保存原始审计副本。脚本中的路径仅为打包复现改成相对路径，数值逻辑不变。主评阅与后续敏感性检查的区别见PROTOCOL.md。
