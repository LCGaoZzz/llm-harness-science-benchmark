模型、积分器与数值边界

这是平面圆型限制性三体模型：地球与月球以固定间距绕质心做圆周运动，航天器质量忽略；无推力、无阻力，也没有太阳摄动。不是现实任务的星历传播器。

01 / 坐标与守恒量

r₁² = (x + μ)² + y², r₂² = (x − 1 + μ)² + y² Ω(x,y) = (x²+y²)/2 + (1−μ)/r₁ + μ/r₂ ẍ = 2ẏ + Ωₓ, ÿ = −2ẋ + Ωᵧ C = 2Ω − (vₓ²+vᵧ²), 零速度曲线: 2Ω = C

原点为地月质心；地球位于 (−μ, 0)，月球位于 (1−μ, 0)。旋转角速度 n = 1。采用 JPL DE440 的地球/月球 GM，μ = GM月/(GM地+GM月)。选定长度单位 384400 km，时间单位 TU = √(DU³/GM总)，而非一个月球周期；一个模型周期是 2π TU。地球、月球保护半径分别取 6371 km、1737.4 km，仅用于表面停止保护。

质心惯性速度是 R(t)(vₓ−y, vᵧ+x)，其速率为 √[(vₓ−y)²+(vᵧ+x)²]。月球引力辅助预设比较相同月心距离处的此速率；不是拿旋转系速度差当作任务 Δv，也没有用推进力增加 C。这是完整模型中有限月心半径处的速率比较，含地球引力的共同作用，不是双曲线无穷远速度 v∞ 或推进系统 Δv。

02 / RK4 与四阶辛分裂

RK4 直接对一阶旋转系方程进行四阶段积分。SY4 则先转换到正则动量，精确求解两个子 Hamiltonian 的流，并用 Yoshida 的对称复合得到四阶方法：

pₓ = vₓ−y, pᵧ = vᵧ+x H = |p|²/2 + y pₓ − x pᵧ − (1−μ)/r₁ − μ/r₂ = −C/2 H_A = |p|²/2 + y pₓ − x pᵧ; H_B = −(1−μ)/r₁ − μ/r₂ A(h): q′ = R(−h)(q+h p), p′ = R(−h)p B(h): q′ = q, p′ = p+h g(q) S₂(h) = B(h/2) A(h) B(h/2) S₄(h) = S₂(w₁h) S₂(w₀h) S₂(w₁h) w₁ = 1/(2−2^(1/3)); w₀ = −2^(1/3)/(2−2^(1/3))

辛性是相空间结构性质，不是 C 的逐步精确守恒，也不意味着在同一步长下总比 RK4 精确。此复合含负子步，近奇点时需谨慎。长期模拟应维持固定步长；手动切换方法或步长会被记录，但不会重置 C₀，也不会对速度进行“守恒量校正”。

03 / 你看到的曲线是什么

L1–L3 用三个不跨奇点的区间二分求解；L4/L5 从非精确初猜进行二维 Newton 求解。界面展示实际残差。零速度边界由视窗内规则网格采样和 marching squares 生成，模糊格用中心值判别；边交点再二分细化。禁止区为 2Ω−C<0。边界默认锁定初始 C₀，绝不追随漂移来掩盖数值误差。自定义 C 时，边界与当前轨迹可能不属于同一能量水平。

接近临界 C 时，极窄的 L1/L2 通道可能小于显示网格而看不清。放大并减小步长分别改善显示和积分，两者互不替代。若 C 低于三角点临界值，可能完全没有零速度曲线，这不是绘制失败。轨迹只来自逐步积分；最多保存 16000 个真实样本，超限后隔点压缩，抽样间隔会在 CSV 中注明。漂移小图显示最近 700 个诊断样本，而最大漂移始终对每一个已接受的积分步统计。

04 / 保护与误差解释

输入 NaN、Infinity、非法步长或天体内部状态会被拒绝；近场步长超限会暂停，保留最后有效状态。表面穿越使用端点与线段保护，未精确定位撞击时间，也未做奇点正则化。没有引力软化，没有穿过天体后的轨迹续画。守恒量漂移小不等于相位准确；不稳定/混沌轨道即使都合理守恒，远期位置仍可显著分离。

画面速率以 TU/s 表示，与步长独立。每帧设置算力预算：预算不足时播放会变慢，不会自动增大 h。切到后台会暂停，避免补算巨量时间。所有数值自检在点击后真实执行；测试容差、测得值和耗时可导出 JSON。
